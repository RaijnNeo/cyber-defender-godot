# Cyber Defender

A cybersecurity simulation game for Android, built in Godot 4 as a group project for our Software Development subject (Universidad de Manila, College of Computing Studies, 2024-2025).

## About the Project

Cyber Defender teaches IT students to recognize cyber threats and practice defensive decision-making through gameplay instead of lectures alone. Players navigate a grid-based "hardware" environment and face off against malware enemies (Trojans, Spyware, Adware, Ransomware, Rootkits) in turn-based combat, choosing the right countermeasure (EXECUTE, KNOWLEDGE, PATCHES, or RUN) to neutralize each threat. The game has three difficulty tiers, Beginner (PCB Sector), Intermediate (Hazard Zone), and Advanced (System Overload), each introducing new mechanics like environmental hazards, stealth/self-healing enemies, and stricter damage modifiers.
